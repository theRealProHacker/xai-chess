Zugzwang Demo

A Lichess-style analysis board (rendered with chessground, the board Lichess uses). Load any position by FEN, play legal moves, then press Detect Zugzwang to run the project's tempo operator (nullzug): it compares Stockfish's evaluation after the best move against its evaluation after a null move (the side to move passes). If passing would be better, the position is zugzwang.
