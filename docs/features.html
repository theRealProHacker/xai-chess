Features

Yes/no positional features, each a fixed rule over the board. Counts and scores are split into one yes/no per value, such as “three pawn islands”. Every feature is checked against up to four positions from master games that a classic book annotated: where the rule and the author agree, and where they part ways.

Where the rule says yes, circles mark the squares it rests on.

Held

Not just how much each piece controls, but how much that control is worth to Leela. Green helps its side, red hurts.

How it is computed Integrated gradients, one run per piece, through the decoder for Leela’s first layer. Only that piece’s control features move, from their average for any piece on its square to their real values; everything else stays as on the board. A piece’s value is how much Leela’s win − loss changes. Kings are not scored.
