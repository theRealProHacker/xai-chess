Obstruct Demo

Mark the line an explanation credits and the engine drops a blocker on it: a phantom that cuts the ray for the pieces that use it — rooks and queens on a rank or file, bishops and queens on a diagonal — and leaves everything else alone. The square stays open; pawns, knights and kings pass through it as before. It then drops the same blocker on squares off the line. Those set the noise floor. A line earns the credit only if every square tried on it moves the evaluation further than an off-line square does. One square doing all the work is that square’s doing, not the line’s.
