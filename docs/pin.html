Pin Intervention Demo

The first rule-level demo. Load a position where the side to move can exploit an absolute pin on an enemy piece (the arrow marks it), then press Suspend the pin. The engine evaluates the position twice on a patched Stockfish 18: once normally, and once with that one pin switched off at the rules level — the pinned piece may move as if it were free, and the pinning line no longer bears on the king. Nothing else about the board changes. If a forced mate (or a winning edge) exists only while the pin holds, the pin is causally load-bearing.

Why rule-level. A board-level test would delete a piece to probe the pin, which also removes its material and every other thing it does. This intervention edits a single rule for a single slider instead, so the counterfactual isolates the pin and nothing else. Demo limits: the search is capped at a fixed node budget, so “no forced mate once suspended” means none was found within that budget; and the lite in-browser engine is weaker than the full oracle, so read the mate / no-mate flip, which is robust, over small centipawn wobble.
