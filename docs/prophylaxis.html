Prophylaxis Demo

A Lichess-style analysis board (rendered with chessground, the board Lichess uses). Load a position with the side you want to defend to move, play exactly one move, then press Detect threat removal to run the project’s threat operator. It asks a narrow, mate-only question: did the opponent have a forced checkmate before your move — found by letting you pass (a null move) — and is that mate gone after it? Search only: no board edits and no engine patch (a Tier 1, confound-free test).

Honest limits. Two — and circularity is not one of them: Stockfish is the oracle, and whether a forced mate exists is an objective fact about the position rather than the oracle’s opinion, so the same engine may pose and answer the threat. What is demo-grade is (1) the node budget: each search is capped, so “no forced mate after your move” means none was found within that budget, not that none exists — the “mate exists” direction is sound, the “mate is gone” direction is not a proof; and (2) the operator only tests that the mate is gone after your move — a crushing counter-attack that merely outruns the mate passes too, so it cannot tell “defended” from “outran.”
