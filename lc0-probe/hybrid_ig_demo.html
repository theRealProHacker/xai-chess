Held-out game, White to move

How it is computed Integrated gradients of Leela’s win − loss, from each square’s average features (over all boards, or over boards where it is empty when it is empty here) to the real ones, through each decoder stack, kept per feature. L0 + L2 + L5 fits the layer-0 decoder first and adds the later decoders in Leela’s stream; L5 + L2 + L0 fits the layer-5 decoder first, then corrections from the layer-2 and layer-0 decoders run through Leela; “with prediction” also feeds those corrections what the stack already predicts.
