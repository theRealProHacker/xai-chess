Family Shapley

Green helps White, red hurts. White is always to move.

How it is computed Each feature family is switched on or off on all squares at once; its Shapley value is its average effect on the decoded win − loss over random orders, through the layer-0 decoder and the rest of Leela. The values add up to the decoded value minus the value with all features off. Pieces held: features whose removal alone moves the value by more than (mostly whole pieces) stay on throughout, and the families split only the rest.
